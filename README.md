# 🛒 SuperStore Sales & Profit Analytics

An end-to-end data analysis and visualization project exploring retail performance, sales trends, category metrics, and profitability across global regions using **Python**, **SQL**, and **Power BI / Data Analytics Tools**.

---

## 📌 Project Overview
This repository contains a detailed analysis of the **SuperStore Sales Dataset**. The project focuses on deriving business insights such as revenue breakdown by category, top-selling products, regional profit performance, and shipping efficiency to optimize retail strategy and operations.

---

## ✨ Key Business Insights & Features
* **Top Product Analysis:** Identification of highest revenue-generating products (e.g., *Motorola Smart Phone*, *Cisco Smart Phone*).
* **Category Performance:** Breakdown of sales and profits across major product categories including **Technology**, **Furniture**, and **Office Supplies**.
* **Regional Profitability:** Geographic evaluation of profit margins across regions (e.g., *Southern Asia*, *Eastern Asia*, *Oceania*, and *Western Europe*).
* **Correlation Metrics:** Understanding relationships between discounts, order quantities, shipping costs, and net profitability.

---

## 🛠️ Tech Stack & Skills
* **Languages & Libraries:** Python (`pandas`, `numpy`, `matplotlib`, `seaborn`)
* **Database & Querying:** MySQL / SQL (`GROUP BY`, `SUM()`, `ORDER BY`, `LIMIT`)
* **Business Intelligence:** Power BI (`.pbix`) Data Modeling, DAX, and Visualizations
* **Data Source:** Microsoft Excel (`superStore.xlsx`)
