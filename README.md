# 🛒 SuperStore Sales & Profit Analytics

An end-to-end data analysis and visualization project exploring retail performance, year-over-year sales growth, category metrics, and global margin performance using **Power BI**, **Python**, **SQL**, and **Excel**.

---

## 📌 Project Overview
This repository contains a comprehensive business analysis of the **SuperStore Sales Dataset**. The dashboard provides key operational insights into order volume, total revenue, regional profit margins, and sales distribution across product categories to guide business strategy.

---

## ✨ Key Dashboard Metrics & Insights

### 📊 Key Performance Indicators (KPIs)
* **Total Orders:** 867
* **Total Sales:** $10.81M
* **Total Profit:** $274.97K

### 💡 Core Visualizations & Analytics
* **Sales by Category:** **Technology** leads with **$4.78M (44.22%)**, followed by **Furniture** with **$3.64M (33.65%)**, and **Office Supplies** at **$2.39M (22.13%)**.
* **Profitability by Category:** **Technology** generates over half of total profits (**$137.88K / 50.14%**), followed by **Furniture** (**$78.74K / 28.64%**) and **Office Supplies** (**$58.35K / 21.22%**).
* **Yearly Sales Growth:** Steady upward trajectory in sales from 2012 (~$1.8M) to 2015 (~$3.9M).
* **Regional Margin Performance:** Detailed evaluation comparing total margin percentages across international regions (e.g., *Eastern US*, *Central Africa*, *Southern US*, *Western Europe*).
* **Global Sales & Profit Map:** Geographical map displaying total sales and profit distribution across global markets.

## 🛠️ Tools & Technologies Used
* **Power BI Desktop (`.pbix`):** Interactive report layout, DAX measures, card visuals, donut charts, map visuals, and line charts.
* **Python (`.ipynb`):** Data cleaning and exploratory analysis using `pandas`, `numpy`, `matplotlib`, and `seaborn`.
* **SQL (`.sql`):** Aggregations, filtering, and revenue queries using `GROUP BY`, `SUM()`, and `ORDER BY`.
* **Microsoft Excel (`.xlsx`):** Raw underlying data source.
