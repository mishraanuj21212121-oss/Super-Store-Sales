# 🛒 SuperStore Sales & Profit Analytics

An end-to-end data analysis and visualization project exploring retail performance, sales trends, category metrics, and profitability across global regions using **Power BI**, **Python**, **SQL**, and **Excel**.

---

## 📌 Project Overview
This repository contains a comprehensive business analysis of the **SuperStore Sales Dataset**. The project focuses on deriving actionable insights such as revenue breakdown by product category, top-selling items, regional profit performance, and shipping efficiency to optimize retail strategy and operations.

---

## ✨ Key Business Insights & Features
* **Top Product Analysis:** Identification of highest revenue-generating products (e.g., *Motorola Smart Phone*, *Cisco Smart Phone*, *Apple Smart Phone*).
* **Category Revenue Breakdown:** In-depth evaluation across major categories—**Technology** ($727K+), **Furniture** ($581K+), and **Office Supplies** ($339K+).
* **Regional Profitability:** Geographic evaluation highlighting top profit centers like *Southern Asia*, *Eastern Asia*, *Oceania*, and *Western Europe*.
* **Correlation Metrics:** Analyzing the impact of discounts, order quantities, and shipping costs on net profit margins.

## 🛠️ Tools & Technologies Used
* **Power BI Desktop (`.pbix`):** Interactive report building, DAX calculations, custom modeling, and interactive dashboards.
* **Python (`.ipynb`):** Data cleaning, exploratory data analysis (EDA), and correlation analysis with `pandas`, `numpy`, `matplotlib`, and `seaborn`.
* **SQL (`.sql`):** Aggregations and database querying using `GROUP BY`, `SUM()`, and `ORDER BY`.
* **Microsoft Excel (`.xlsx`):** Primary data source.
